# EVE Algo Lab — Project Status

- Automatic completed-candle syncing.
- Learning snapshots and forward-outcome labels.
- Autonomous prediction grading and challenger-model control.

v2.0 generates and evaluates research-grade strategy specifications. It does not yet generate an MT5 EA or approve live trading. High-resolution replay and forward validation are later gates.
