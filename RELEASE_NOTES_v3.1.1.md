# EVE Command Centre v3.1.1 — Sidebar viewport hotfix

This release changes only the desktop navigation layout.

- The left sidebar now always fits the browser viewport.
- The EVE brand and Railway service status remain visible.
- The navigation list scrolls independently on short laptop screens.
- A visible thin scrollbar appears only when the menu needs it.
- Mobile horizontal navigation remains unchanged.
- Research, mutation, validation, MT5 generation, fleet telemetry and Supabase logic are unchanged.

No Supabase SQL or environment-variable changes are required when upgrading from v3.1.
